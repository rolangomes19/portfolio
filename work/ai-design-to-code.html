Hypothesis

A design system with full token coverage and Figma-to-code parity should give an LLM everything it needs to generate compliant frontend code directly — not as a novelty, but as a repeatable path from a Figma file to shippable output. WorkFeed v2, a concept for Wipfli Hub, was the test case.

Prerequisites

This only works because Blueprint already existed: three-tier tokens, a documented component library, and Code Connect links tying every Figma component to its real code counterpart. Without that structure, an LLM has nothing precise to point at — it's guessing from screenshots, the exact failure mode Blueprint was built to remove in the first place.

Direction method

I designed the WorkFeed v2 concept in Figma using Blueprint components exclusively, then directed an LLM to generate the frontend from those linked components rather than from a visual description — treating the design system as the instruction manual, and my own prompts as the spec, not a suggestion.

Output

The result was an 80% component match rate against the Figma spec, delivered in a 7-day turnaround. The POC is currently under evaluation for production use at Wipfli Hub.
